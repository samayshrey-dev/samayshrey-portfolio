## Getting Started

Clone the repository:

```bash
git clone https://github.com/samayshrey-dev/samayshrey-portfolio.git
```

Navigate to the project:

```bash
cd samayshrey-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
